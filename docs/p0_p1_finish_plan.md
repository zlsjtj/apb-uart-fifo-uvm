## 要完成的事

1. STATUS bit7 增加 TX_BUSY。成功写 TXDATA 后不能短暂误报完成；最后一个停止位走完后才允许清零。FIFO 空、配置传递完成、串行发送完成分别表达，不混用。
2. 统一帧间配置约定。正常收发先完成配置轮询，修改配置前等待发送排空，并由外部协议保证 RX 没有在途帧。帧中禁用属于中止，不承诺原帧完整送达。
3. UART agent 不再创建或索取内部配置探针。白盒配置监视移到环境层，提供显式开关及配置事件检查；无探针模式必须通过公开接口收发测试。
4. 完整 UVM 顶层支持 FIFO 深度参数。深度 2、4、16、64 分别测试满空、数据顺序、回绕和复位恢复；增加独立 FIFO 随机双时钟检查和源域 Gray 指针性质检查。

## 验收方法

- 修改期间先编译和定向测试，再跑完整回归。
- 至少两轮完整本地验收，使用不同 seed；最终源码的结果单独记录，不把旧版本运行次数累加到新版本。

- 发送提前完成故障必须由公开接口测试检出；没有探针也必须能完成基础数据验证。
