# 本轮工程整理计划

接着已经通过的 P0/P1 做工程整理，不再改 UART 功能。之前未提交的源码和说明一并保留，最终以本轮完整验收的源码身份提交。

1. 统一工具配置；完整验收先检查版本、器件支持与实际仿真启动。
2. 按 runId 从独立快照导出交付目录；相对路径和 SHA-256 校验通过后才更新发布入口。
3. 保留固定种子，新增 campaign seed 扩展压力及 mutation；故障与正确基线必须同测试、同种子。
4. 当前说明与历史记录分开；论文结果表从选定运行生成。

验收至少两轮，正式回归基准 seed 与 campaign seed 均不同。原有覆盖率、CDC、综合、参数、无探针和 mutation 门禁全部保留，不降阈值、不放宽 waiver。环境与交付流程增加正反向测试。源码改变后，旧结果不能作为新代码的最终证据。

对真实交付包做搬移校验和失败发布检查，再 commit、push 并核对远端。真实异步 RX、布局布线、上板和商业 CDC/RDC 签核不在本轮范围内。
