# P0/P1：发送完成状态与验证复用

## 本轮改动

### 发送完成不再靠 FIFO 空来猜

STATUS bit7 新增 TX_BUSY，原有地址和低 7 位含义不变。APB 域累计成功接收的 TXDATA 写；UART 域在完整停止位结束后累计完成数，再将寄存后的 Gray 计数通过两级同步器返回。两边计数不相等时为 busy。这样刚写入的数据即使还没跨到 UART 域，也不会被旧的空闲状态漏掉。

计数宽度取 FIFO 地址宽度加 2，给最小深度和完成流水级留出余量。发送一帧后既可连续发送下一帧，也可转为空闲，不额外插入一个串行位的间隔。Gray 单步断言放在源域；综合流程对新增计数通路设置 max_delay 和 bus_skew，并单独审核 CDC 路径。

普通配置流程现在先等待 TX_BUSY 和 CFG_BUSY 都清零，再写 CTRL/BAUD，写后再次等待 CFG_BUSY 清零。外部 RX 仍需由通信协议保证在这段时间没有在途帧。原始访问接口保留给邮箱突发、复位和显式中止测试；它不自动执行安全配置流程。

显式 disable 可中止当前帧，reset 可丢弃排队和在途数据。因此这两种操作后的 busy 清零不是“数据已经成功送达”。独立 APB 测试分别在数据位和停止位期间 disable，检查状态不会卡住。

### 普通 UART agent 与白盒检查分开

uart_agent 不再创建配置 monitor，也不再索取 uart_probe_if。可选配置 monitor/checker 在 env 层创建并显式连接，它们不修改串行参考配置，也不提供期望数据。普通 TX/RX 监视继续从公开引脚解码。

NoWhitebox 是独立编译配置：移除依赖探针的类及顶层接口实例，而不是保留一个空接口。这样也兼容本机旧版 Questa 对虚接口的加载要求。无探针测试包括发送完成、外部 RX、FIFO 回绕、RX 满和帧中复位恢复。

### 参数验证从单元延伸到完整环境

UVM 顶层的 FIFO_ADDR_WIDTH 改为可传入参数，通过 env_cfg 传给 predictor 和满空、回绕激励。正式参数子集选深度 2、4、16、64，每种深度运行发送完成、回绕、TX 满、RX 满及两种复位测试。另有深度 2、UART 快于 APB 的边界配置。

独立 FIFO 单元测试使用公开读写口维护软件队列，比较每次接受的读数据；两种相反的读写速度下进行填满、排空、随机并发及流量中复位。复位丢弃的软件队列明确清空，不把有意丢弃的数据算作顺序错误。
